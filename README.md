## 🎮 ویژگی‌ها

- **۳ سطح دشواری**: آسون، متوسط، سخت
- **راهنمایی هوشمند**: سیستم گرم/سرد به کمکت میاد
- **سیستم امتیازدهی**: هر چی سریع‌تر حدس بزنی امتیاز بیشتری میگیری

## 🛠️ نصب و اجرا

**پیش‌نیاز**: Python 3.6 یا بالاتر

```bash
# ۱. ریپو رو clone کن
git clone https://github.com/username/number-guessing-game.git

# ۲. وارد پوشه بشو
cd number-guessing-game

# ۳. بازی رو اجرا کن
python number_game.py
```
